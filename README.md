# Comparative Analysis of Sorting Algorithms 
A comprehensive benchmarking project that analyzes the performance, time complexity, and stability of various sorting algorithms using Python.

##  Project Overview
Sorting is a fundamental operation in computer science. This project evaluates **10 different sorting algorithms**, covering both comparison-based and non-comparison-based techniques. The goal is to determine the optimal algorithm for specific real-world edge cases based on dataset sizes ranging from **1,000 to 100,000 elements**.

##  Technologies Used
*   **Language:** Python
*   **Environment:** Jupyter Notebook
*   **Libraries:** Matplotlib (for data visualization), NumPy

##  Algorithms Analyzed
### Comparison-Based Algorithms
*   Quick Sort
*   Merge Sort
*   Heap Sort
*   Bubble Sort
*   Insertion Sort
*   Selection Sort

### Non-Comparison-Based Algorithms
*   Counting Sort
*   Radix Sort
*   Bucket Sort

##  Key Features & Metrics Evaluated
1.  **Execution Time:** Benchmarking actual runtime across varying dataset sizes.
2.  **Time Complexity:** Comparing theoretical Big-O limits (Best, Average, Worst cases) with empirical data.
3.  **Space Complexity:** Analyzing memory consumption during execution.
4.  **Algorithm Stability:** Evaluating whether algorithms maintain the relative order of records with equal keys.
5.  **Data Visualization:** Utilizing Matplotlib to generate line graphs comparing the performance of all 10 algorithms simultaneously.
